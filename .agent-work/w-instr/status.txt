## 1. What increments droppedFrames_? (quoted)

media_player.cpp present loop (after full frame read, ++frameIndex):
  frameMs = frameContentMs(frameIndex, fpsNum, fpsDen) + avOffsetMs_
  clockMs = audibleClockMs(audioBytes_, audioQueuedBytes_) if audio else (now-t0)
  drift = avDriftMs(clockMs, frameMs)   // audio/wall − content
  act = avDecide(drift, leadMs, dropMs, dropRun)
  if !present: droppedFrames_.fetch_add(1)   // NO presentCleanFrame
  else: presentCleanFrame(...); dropRun=0

av_clock.hpp:37-64:
  drift<0 video ahead → Hold; drift>0 video behind → Drop
  Drop iff dropMs>0 && driftMs>dropMs && dropRun<maxDropRun(default 1)
  Hold iff driftMs+leadMs < 0

Defaults: presentLeadMs_=40, resyncDropMs_=80 (media_player.hpp:335-336).
ONLY this path increments droppedFrames_. publish_misses_ is DDR fail path.
