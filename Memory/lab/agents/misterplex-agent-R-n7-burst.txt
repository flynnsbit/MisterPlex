### Handshake note (for later n7 store — R-n7-policy owns that sibling)
One qword = 4 x 16-bit. Start addr[2:1]==2'b00 (sequential BL=4 wrap box).
1. ST_IDLE ready=1: issue beat0 (sel+wr+addr+din) exactly as today's S_WR_ISSUE.
2. ready=0 during ACT+tRCD. Do not start a new ACT.
3. WRITE cycle: ready=1 for 3 consecutive cycles (beat strobe). Registered store (default-clear sel/wr, pulse on ready) sees ready on cycle K and must present sel=1, wr=1, din=next beat on cycle K+1. Controller samples din on the 3 ST_WR_BURST cycles. addr on beats 1..3 ignored.
4. After beat 3: ready=0 for tRP, then ST_IDLE.
