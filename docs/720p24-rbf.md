# 720p24 RBF (fork of the v0.4.1 true480 QSF)

The glass-good **240p/480p** pair stays `Plex.qsf` / RBF md5 `07f54d9f`.
Do not change `clk_sys` on that file. 24 unique fps at **1280×720** needs a
sibling fit: `fpga/Plex_MiSTer/Plex_720p24.qsf`.

## Why a second QSF

| | true480 product | 720p24 fork |
|--|--|--|
| clk_sys | 20 MHz | **24 MHz** (`PLEX_CLK_SYS_24`) |
| Beam | 672×496 CE/2 → 30.0019 Hz | 1312×762 → **24.006 Hz** |
| Store | 624/618/640 @ `0x30000000` | 1280×720 @ `0x30180000` |
| Prefetch | 8 lines | 16 lines |
| 240/480 glass | production | **not this RBF** |

A 20 MHz L4 beam is 20.005 Hz (L47). Raising `clk_sys` on the 480p QSF would
break the proven 30.0019 Hz contract. Hence a fork, not a toggle on the
shipping file.

## Fit (exclusive, parent only)

```bash
# Copy recipe over the live project file for one exclusive remote fit,
# or point the farm at Plex_720p24.qsf. Never fit locally.
cp fpga/Plex_MiSTer/Plex_720p24.qsf fpga/Plex_MiSTer/Plex.qsf
# then scripts/build_rbf_remote.sh
```

Restore `Plex.qsf` from git before any 480p rebuild.
