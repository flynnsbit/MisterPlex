## Copy-over recipe (parent only, after exclusive FREE)

Never overwrite shipping `Plex.qsf` in a product tree while another
compile is LIVE. Isolated slot only.

### Preferred — `scripts/prep_sibling_fit_slot.sh`

Dry-run is the default (prints the plan, copies nothing). `FIT=NO`.

```bash
# from this worktree (or the 480i-fit snapshot)
scripts/prep_sibling_fit_slot.sh Plex_480i.qsf
# after exclusive is FREE — never SLOT=crt240p15
scripts/prep_sibling_fit_slot.sh --apply Plex_480i.qsf
# default SLOT=/home/flynnsbit/mplex-builds/Plex_480i
```

Refuses (exit 4) if `/tmp/misterplex-exclusive.lock` exists, docker
`mplex-fit-*` is Up, SLOT is the live `crt240p15` path, or dest would
overwrite this tree's shipping `fpga/Plex_MiSTer`. Exit 3 if the sibling
QSF is missing. Does **not** launch Quartus.

### Fallback — 720p24-style `cp` in an isolated slot

```bash
SLOT=/home/flynnsbit/mplex-builds/Plex_480i   # never crt240p15
mkdir -p "$SLOT"
rsync -a \
  --exclude '/db/' --exclude '/incremental_db/' --exclude '/output_files/' \
  --exclude '/remote_out/' --exclude '/greybox_tmp/' --exclude '/build/' \
  --exclude '*.qws' \
  fpga/Plex_MiSTer/ "$SLOT/Plex_MiSTer/"
cp "$SLOT/Plex_MiSTer/Plex_480i.qsf" "$SLOT/Plex_MiSTer/Plex.qsf"
# then scripts/build_rbf_remote.sh pointed at that slot — parent only
```

Restore product `Plex.qsf` from git before any 480p rebuild. Do not
leave `Plex_480i.qsf` copied over the shipping file.
