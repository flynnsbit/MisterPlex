inside the previous 512-bit window.

Reuse: if win_valid && bit_pos ∈ [res_win_bit0, res_win_bit0+256]

  pulse cavlc_start → ST_RES_WAIT.

win_valid set on completed WIN_LOAD; clear on slice/rbsp reload.

No new memory (res_win already 64×8 regs). No mul.
