## Two pipelines (do not conflate)
1) **Product silicon today (parent-verified):** ARM software decode + DDR I420 present.
   - frame_tx ~4 ms @240p (parent log ms=4; w-bw model 4.06 ms).
   - Frame period @24 fps = 41.67 ms → present uses ~10% of period.
   - DDR need 2.76 MB/s vs peak ~720 MB/s @64b/90 MHz → bandwidth NOT binding.
2) **FPGA H.264 decode path (Verilator paint_per_mb):** meets 240p@24/25; not yet
   30/60 or 480p. Not what is driving the current cast playback vfps.
