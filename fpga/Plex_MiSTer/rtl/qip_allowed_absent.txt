# Product RTL that is legitimately absent from the Quartus file list.
#
# Every entry needs a reason. An unexplained exclusion is how a real defect
# hides -- this project has shipped three subsystems that were written, unit
# tested green, and not in the bitstream.
#
# This manifest is a RATCHET, not an escape hatch:
#   * an entry whose file is now compiled  -> STALE_ALLOWED_ABSENT, hard fail
#   * an entry whose file no longer exists -> STALE_ALLOWED_ABSENT, hard fail
#   * an entry with no reason              -> ALLOWED_ABSENT_NO_REASON, hard fail
# so the allowlist cannot silently absorb progress or a regression.
#
# format: <basename or rtl-relative path>  # reason
cos.sv  # unused helper, never instantiated by the product
h264_decode_skeleton.sv  # retired lineage (architectural ruling); not a product module
lfsr.v  # legacy MiSTer template leftover, no product instantiation
mycore.v  # legacy MiSTer template leftover, no product instantiation
pll.v  # Quartus-generated PLL wrapper; compiled via the generated pll.qip when used
pll/pll_0002.v  # Quartus-generated PLL megafunction body, driven by pll/pll_0002.qip
